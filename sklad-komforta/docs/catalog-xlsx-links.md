# Связи товаров в XLSX

Новые экспорт и шаблон используют формат 3. Импорт файлов формата 2 с UUID
по-прежнему поддерживается.

## Заполнение

1. Заполните товары на листах категорий. Служебный ID скрыт; у нового товара он пустой.
2. Откройте нужный лист «Связи N». В заголовке указаны категории основного
   и связанного товара.
3. В колонке A выберите основной товар, в B выберите связанную позицию.
   Подпись содержит название, маркировку, цену и номер для различения одинаковых позиций.
4. Для нового товара вместо A заполните C: номер его строки на листе категории,
   указанном в инструкции. Например, первая строка данных имеет номер 3.
5. Для нескольких связей добавьте несколько строк. Повторы одной пары при импорте
   объединяются. Удаление строки снимает эту связь у импортируемого товара.

В шаблоне без товаров колонка A пуста: используйте C. В колонке B доступны
существующие товары разрешённой категории, включая товары вне фильтра экспорта.
Новые связанные позиции сначала нужно создать в каталоге и скачать свежий шаблон.
Выпадающие списки подготовлены минимум до строки 2000; при добавлении строк ниже
копируйте ячейки вместе с проверкой данных.

Цена в подписи является снимком на момент выгрузки, а не ценой для импорта.
Соответствие подписи и ID хранится на скрытом листе. Изменение цены в каталоге
после скачивания файла не переназначает связь. Не редактируйте подписи вручную
и не удаляйте служебные листы. При изменении зависимостей скачайте новый файл.

Импорт проверяет выбор товаров и актуальность разрешённых зависимостей.
Неизвестная подпись, отсутствующий лист связей или неоднозначный основной товар
приводят к сообщению об ошибке, а не к молчаливому удалению связей.
