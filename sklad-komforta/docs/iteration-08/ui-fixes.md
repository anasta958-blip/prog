# Адаптивный интерфейс Flutter

## Область изменений

Исправления относятся к `src/flutter`: раскладка, отображаемые подписи,
навигация редакторов, локальные предпочтения и момент загрузки PDFium.
Серверные права, расчёты, формат сохраняемых документов и схема БД не меняются.
Миграций и новых переменных окружения нет. Коммиты не создавались.

## Состояние приёмки

Автоматическая проверка 09.10.2026: `flutter analyze` без замечаний,
полный `flutter test` — 187 успешных тестов.
Это не означает проверку всех экранов со всеми данными на всех разрешениях.
Браузерная приёмка на 375×812 и 1024×768 пока не выполнена: инструменты
управления текущей сессией завершаются ошибкой запуска Node/sandbox до
получения состояния вкладки. Авторизованная сессия не изменялась инструментами.
Не проверены вручную PDF-счёт, Network/консоль при старте и восстановление
разделов после обновления браузера. Полная приёмка задачи остаётся открытой.

Отладочный `flutter run -d web-server --web-port=3000` успешно скомпилирован
и запущен с остановленным контейнером web; HTTP-проверка корня вернула 200.
Процесс завершён штатной командой `q`. Это проверка запуска, не визуальный обход.
После этого `docker compose up -d --build web` успешно завершён. Контейнер web
работает на порту 3000, HTTP-проверка вернула 200. Release-сборка предупреждает
о необнаруженном семействе CupertinoIcons; это не ошибка компиляции, но
наличие всех значков следует проверить при визуальном обходе.

## Точки перехода

- Рабочая оболочка: настольная от 840 px; ширина бокового меню 248 px,
  свёрнутого — прежняя. Редакторы сохраняют прежний переход 900 px.
- Командная панель документа: до 600 px вторичные действия и выбор КП/ПКП
  находятся в меню; до 760 px сохранение — иконка, заголовок сокращён с номером;
  от 600 до 1099 px вторичные команды — иконки; от 1100 px — с подписями.
- Строка настройки столбца и карточки компании: компактная при доступной
  ширине меньше 520 px. Поля диалогов: одна колонка до 520, две до 760.
- Мобильная оболочка настроек компании: до 840 px. Выбор раздела конфигурации
  при доступной ширине меньше 1024 px — список, выше — переносимые кнопки.
- Фильтры канбана: три поля в строке при доступной ширине от 650 px;
  поиск имеет ширину 240 px. Общая строка с заголовком — от 1150 px.
- Заголовок категории документа: две строки до 600 px; раздела — до 760 px.
- Каталог: до 600 px по умолчанию список, если пользователь не сохранял выбор.
  Кнопки редактора товара переносятся по фактической доступной ширине.

Все значения, кроме явно указанных размеров оболочки, относятся к доступной
ширине компонента, а не физическому разрешению монитора.

## Контракты и хранение

- `DocumentCommand` связывает подпись, иконку и исходный callback команды;
  `DocumentCommandBar` отвечает только за представление, не сохраняет документ.
- `backRequest` — изменяемый сигнал повторного выбора канбана, а не обход
  проверки несохранённых изменений. Существующие callbacks выхода сохранены.
- `PreviewTable` принимает таблицу и минимальную ширину, меняет ширину колонки
  наименования; данные позиций не преобразует.
- `AppNumberField.groupThousands` по умолчанию выключен. Для денежных полей
  разделители относятся только к отображению; onChanged/validator/onSubmitted
  получают строку без пробелов. Ограничения минимального значения сохранены.
- `russianCount` выбирает форму по целому числу; `russianPercent` принимает
  уже рассчитанное значение в процентах, без дополнительного умножения на 100.
- `catalog.list_view.v1` в существующем FlutterSecureStorage хранит только
  строковое булево предпочтение. Ошибка хранилища не блокирует каталог.
- `workspace_address` использует условный web-импорт без пакета маршрутизации.
  Пути: `#/kanban`, `#/catalog`, `#/company/<имя enum>`, `#/devices`.
  Неизвестный путь возвращает канбаны. История Back/Forward отдельно не реализована.
- PDF-инициализация использует существующий pdfrx; ошибка загрузки показывается
  в окне просмотра, серверное скачивание и авторизация не изменены.

