## Уточнение раскладки и прокрутки, 10.10.2026

Последующие четыре замечания исправлены без изменения данных и команд:

1. В мобильном заголовке категории стрелка, папка и название теперь находятся
   в одном ряду с общей вертикальной осью. Суммы и действия занимают следующий
   ряд по всей ширине, а не внутри отступа названия. До 670 px содержимого
   используется двухрядная раскладка, выше сохраняется один ряд.
2. На настольной ширине КП/ПКП реквизиты, сводки, селекторы и позиции включены
   в общую вертикальную прокрутку. Командная панель остаётся закреплённой,
   как на телефоне. Комплектация уже использовала общую прокрутку; её поведение
   закреплено регрессионным тестом.
3. Категория, раздел и статус каталога стоят в одном ряду от 650 px доступного
   содержимого. Поле категории в этом ряду имеет ширину 230 px и ту же компактную
   высоту, что раздел и статус; размеры проверяются тестом на 1024/1440.
   При меньшей ширине ряды переносятся; мобильное раскрытие фильтров
   сохранено.
4. Тип, вариант и НДС располагаются рядом от 980 px доступного содержимого.
   Место учитывает кнопки действий; ниже используются прежние адаптивные ряды.

Расширены существующие widget-тесты: координаты иконки/названия категории,
сохранение всех вариантов, положение типа/варианта и прокрутка реквизитов
проверены для КП и ПКП на 320/375/600/800/1024/1440; положение фильтров каталога
проверено на 1024/1440, мобильный каталог на 375; прокрутка комплектации
проверена на 1024/1440. Полный набор содержит 194 теста.

Итоговый запуск после этих четырёх изменений: 194 теста прошли,
`flutter analyze` без замечаний; `docker compose up -d --build web`
успешно завершён, контейнер запущен. Предупреждение release-сборки
о CupertinoIcons осталось прежним.

Отдельно обнаружено не относящееся к этим четырём изменениям переполнение
панели счетов комплектации на 375 px при выбранных PDF. Исправление этой панели
не включено в текущую правку. Визуальная браузерная проверка по-прежнему не выполнена.

## Контракты и хранение

Шапка каталога приведена к оформлению рабочих областей: отдельная верхняя
полоса без отступов содержимого, фон #101823, нижняя граница #253348,
иконка каталога и компактный жирный заголовок. Высота на широком экране —
68 px плюс граница 1 px; при нехватке места действия переносятся.
Обновление, шаблон, импорт, экспорт и создание товара сохранены.
Мобильное раскрытие управления и меню действий не изменены.
Widget-тест каталога проверяет положение и размер шапки на 1024/1440,
а также отсутствие переполнения на 375.

- `DocumentCommand` связывает подпись, иконку и исходный callback команды;
  `DocumentCommandBar` отвечает только за представление, не сохраняет документ.
- `backRequest` — изменяемый сигнал повторного выбора канбана, а не обход
  проверки несохранённых изменений. Существующие callbacks выхода сохранены.
- `PreviewTable` принимает таблицу и минимальную ширину, меняет ширину колонки
  наименования; данные позиций не преобразует.
- `AppNumberField.groupThousands` по умолчанию выключен. Для денежных полей
  разделители относятся только к отображению; onChanged/validator/onSubmitted
  получают строку без пробелов. Ограничения минимального значения сохранены.
- `russianCount` выбирает форму по целому числу; `russianPercent` принимает
  уже рассчитанное значение в процентах, без дополнительного умножения на 100.
- `catalog.list_view.v1` в существующем FlutterSecureStorage хранит только
  строковое булево предпочтение. Ошибка хранилища не блокирует каталог.
- `workspace_address` использует условный web-импорт без пакета маршрутизации.
  Пути: `#/kanban`, `#/catalog`, `#/company/<имя enum>`, `#/devices`.
  Неизвестный путь возвращает канбаны. История Back/Forward отдельно не реализована.
- PDF-инициализация использует существующий pdfrx; ошибка загрузки показывается
  в окне просмотра, серверное скачивание и авторизация не изменены.

## Проверки

Новые файлы тестов: `document_command_bar_test.dart`,
`preview_table_layout_test.dart`, `russian_formatters_test.dart`.
Дополнены тесты селекта, числового поля, аудита, компании, канбана,
редакторов КП/комплектации, настройки переноса и каталога.

Команды из `src/flutter`:

```powershell
flutter analyze
flutter test
flutter run -d web-server --web-port=3000 --dart-define=API_BASE_URL=http://localhost:8080/api/v1 --dart-define=PUBLIC_APP_BASE_URL=http://localhost:3000
```

Перед отладочным сервером из корня: `docker compose stop web`.
После проверки вернуть контейнер: `docker compose up -d --build web`.
Сгенерированные исходники вручную не редактируются.
