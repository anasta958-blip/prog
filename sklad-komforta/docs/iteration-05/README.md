# Итерация 5. Компания

## Цель

Итерация превращает пространство «Компания» в рабочий multi-tenant модуль. Оно
содержит настройки организации, клиентов, сотрудников с древовидной структурой
и права доступа. Подрядчики в новой системе отсутствуют.

## Реализовано

- несколько юридических лиц в одной организации и один исполнитель по умолчанию;
- отдельный справочник клиентов;
- обязательная учётная запись каждого сотрудника;
- строго одна роль и не более одного непосредственного руководителя;
- разрешённые связи ролей и фактическая структура сотрудников хранятся отдельно;
- циклы ролей и сотрудников блокируются сервером;
- руководитель структурно получает всю нижестоящую ветку, а сворачивание дерева
  остаётся только состоянием интерфейса;
- единый `active_until` организации используется директором и сотрудниками;
- просроченная организация блокируется при входе, обновлении токена и каждом API-запросе;
- создание, изменение и удаление сущностей записывается в tenant-аудит;
- настройки организации в рабочем пространстве отображаются вкладками, а не
  повторным мастером первичной активации;
- роли исключены из общего сохранения конфигурации и больше не перетираются.
