# Фильтр карточек канбана по пользователю

## Назначение

Рядом с выбором рабочего канбана находится фильтр авторов карточек. Он позволяет
показывать собственные карточки, карточки одного разрешённого сотрудника либо обе
группы одновременно.

Доступные варианты:

- `Свои` — только карточки, созданные текущим пользователем;
- имя сотрудника — только карточки выбранного сотрудника;
- `Свои и {имя сотрудника}` — карточки текущего и выбранного пользователей.

Список сотрудников не является общим списком организации. Backend формирует его
по настройке `Видимость карточек` текущей роли: все сотрудники, нижестоящая ветка
иерархии либо явно выбранные сотрудники. Собственный пользователь включается
всегда. Неактивные и удалённые сотрудники не выдаются.

## API

- `GET /api/v1/kanbans/card-authors` возвращает разрешённых авторов.
- `GET /api/v1/kanbans/{boardId}/cards` принимает необязательные параметры
  `authorUserId` и `includeOwn`.

Отсутствие `authorUserId` означает выбор `Свои`. Переданный идентификатор повторно
проверяется на сервере. Изменение URL или прямой API-запрос не позволяют получить
карточки сотрудника, которого текущая роль видеть не может.

## Flutter

`KanbanController` хранит выбранный режим и передаёт его при загрузке каждой
страницы каждого столбца. Смена фильтра не перезагружает конфигурацию канбана:
обновляются только страницы карточек. Для выпадающего списка используется общий
`AppSelectField`, который открывает меню под полем или над ним при нехватке места.
