# Проверка итерации 5

## Автоматические проверки

```powershell
dotnet build SkladKomforta.sln --no-restore
dotnet test SkladKomforta.sln --no-build

cd src/flutter
flutter analyze
flutter test
```

Интеграционные smoke-тесты проверяют авторизацию новых endpoint-ов. Flutter-
тесты проверяют управляемое содержимое подпространств, рабочие вкладки
настройки без внутреннего дубля навигации, независимую
обработку запрета раздела и визуальное сворачивание ветви сотрудников.

Контрольный прогон итерации: 52 backend unit-теста, 23 API integration-теста и
32 Flutter-теста пройдены; `flutter analyze` и `dotnet build` завершены без
замечаний. Контейнеры `api` и `worker` пересобраны, `/health/live` отвечает
`Healthy`.

## Docker

```powershell
docker compose up -d --build api worker
docker compose ps
docker compose logs --tail=80 api worker
```

После применения миграций нужно проверить:

1. создание второго юридического лица и переключение значения по умолчанию;
2. создание клиентов типов «Физическое лицо», «ИП» и «ООО» с сохранением
   соответствующих реквизитов;
3. создание роли с подчинённой ролью;
4. создание сотрудника с логином, ролью и руководителем;
5. запрет цикла и второго руководителя;
6. немедленное прекращение доступа после отключения сотрудника;
7. отказ login/refresh/API после `active_until`.
