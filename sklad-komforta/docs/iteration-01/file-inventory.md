# Инвентаризация файлов текущего проекта

Документ описывает ответственность файлов, важную для переписывания. Внутренние вспомогательные функции переносятся по бизнес-модулям, а не копируются один в один вместе с текущими глобальными именами.

## Корень

- `index.php`: собирает все шаблоны, объявляет lazy-assets и подключает базовый JavaScript.
- `quote.php`: публичная страница КП/ПКП по токену, подсчёт просмотров, выбор варианта/типа и печатное представление. Публичный доступ не переносится.
- `schema.sql`: актуальная локальная MySQL-схема из 25 таблиц.
- `version.json`: сгенерированный хеш версии frontend/backend-файлов.
- `README.md`: устаревшее описание; русский текст физически повреждён mojibake.
- `package.json`: только Playwright и browser PDF-зависимости, не production frontend build.

## `includes`

- `auth.php`: сессии, CSRF, PDO, справочники, JSON envelope, текущий пользователь, роли, права и области видимости.
- `access_middleware.php`: сопоставляет API actions с разрешениями.
- `pagination.php`: разбор `page/per_page`, SQL limit и envelope пагинации.
- `assets.php`: cache-busting отдельных файлов и общий хеш версии приложения.
- `quotes/quote_common.php`: общие функции КП/ПКП — JSON, доступ, компания, числа, нормализация payload, расчёты, нормализованные таблицы, PDF/ИНН helpers и сводки.

## `api`

- `auth.php`: login, текущая сессия, logout.
- `permissions.php`: чтение и сохранение политик ролей.
- `users.php`: список, создание, редактирование, директор, удаление и перенос владения данными.
- `meta.php`: агрегированные справочники приложения.
- `catalog.php`: весь каталог, справочники, импорт, карточки товаров, работы и связи.
- `kp.php`: КП, компании, клиенты, подрядчики, каталог builder, канбан, перенос в комплектацию и workflow email.
- `pkp.php`: ПКП, большая часть общих операций КП и перенос в КП.
- `orders.php`: комплектация, строки, счета, статусы, архив и связанные уведомления.
- `documents.php`: шаблоны, версии и загрузка изображений.
- `email.php`: PHPMailer/SMTP/mail и endpoint отправки вложения.
- `telegram.php`: отправка PDF/HTML в Telegram.
- `version.php`: проверка версии приложения с освобождением session lock.

## Базовый JavaScript

- `app.constants.js`: коды пространств, роли, цвета, вкладки и глобальные константы.
- `app.state.js`: глобальное состояние текущего пользователя, справочников, пространств и builder-ов.
- `app.api.js`: fetch wrapper, CSRF, API envelope, кэш пользователей.
- `app.loader.js`: lazy-load скриптов по пространствам.
- `app.init.js`: начальная загрузка пользователя и метаданных.
- `app.auth.js`: форма входа/выхода и синхронизация сессии.
- `app.nav.js`: пространства, маршрутизация, восстановление вкладки/скролла.
- `app.modals.js`: общие модальные окна и подтверждения.
- `app.helpers.js`: форматирование, escaping, toast, архив/удаление и разрозненные UI helpers.

## Builder комплектации

- `builder/core.js`: модель категорий/разделов/строк, выбор справочников и базовые изменения.
- `builder/catalog-fields.js`: autocomplete группы, названия и маркировки, заполнение карточки.
- `builder/flow.js`: клавиатурный ввод, Enter-переходы, количество и autocomplete flow.
- `builder/dom.js`: точечные DOM-обновления строк и итогов.
- `builder/render.js`: HTML категорий/разделов и полная первичная отрисовка.
- `builder/drafts.js`: локальные черновики и защита несохранённых изменений.
- `builder/save.js`: сохранение комплектации, печать и отправка PDF/email/Telegram.

## Пространства

- `spaces/catalog.js`: состояние каталога, фильтры, пагинация, карточки и модальные формы.
- `spaces/orders.js`: канбан комплектации, drag-and-drop, карточка редактирования и счета.
- `spaces/users.js`: карточки пользователей, дерево компании и меню действий.
- `shared/employees.js`: общее представление сотрудников.
- `spaces/settings.js`: единицы, поставщики, группы и права.

### КП/ПКП

- `spaces/kp/state.js`: единое состояние режимов КП/ПКП, статусы, типы и варианты.
- `spaces/kp/catalog.js`: загрузка справочников и каталог внутри builder.
- `spaces/kp/builder-core.js`: создание/редактирование структуры предложения и строк.
- `spaces/kp/render.js`: канбан, карточки и builder UI.
- `spaces/kp/save.js`: сохранение, черновики, печать и шаблоны документов.

### Документы

- `spaces/documents.js`: весь конструктор документов в одном файле: state, API, блоки, layout, drag, resize, страницы, печать и PDF. В новой системе должен быть разделён как минимум на domain state, editor interactions, layout engine, renderer, persistence и PDF contract.

## `templates`

- `layout/*`: login и оболочка приложения.
- `spaces/catalog/*`: каталог.
- `spaces/kp/*`: каталог КП, компания, клиенты, подрядчики, builder и канбан.
- `spaces/orders/*`: канбан, новая заявка, редактирование, сотрудники и каталог комплектации.
- `spaces/documents/builder.php`: оболочка конструктора документов.
- `spaces/settings/*`: пользователи, права и справочники.
- `modals/all.php`: общие формы каталога и других пространств.
- `catalog_import_*_template.csv`: старые шаблоны импорта; новая система получает новые XLSX-шаблоны.

## Миграции и тесты

- `migrations/20260704_quote_payload_normalization.sql`: нормализованные варианты и позиции КП/ПКП.
- `migrations/20260710_incidental_expense_price_type.sql`: тип цены сопутствующих расходов.
- `migrations/20260711_consumables_category.sql`: категория расходных материалов.
- `migrations/20260717_document_template_type.sql`: тип документа у шаблонов.
- `tests/e2e/*`: Playwright-сценарии авторизации, прав, builder, черновиков, документов, групп и русских строк.
- `tests/setup-test-db.ps1`: создание тестовой MySQL-базы.
- `tests/start-test-server.ps1`: локальный PHP server.

## Не переносится как production-код

- `node_modules`, `playwright-report`, `test-results`;
- локальные PHP session-файлы;
- текущая browser-only реализация публичной ссылки;
- локальные пути XAMPP;
- fallback подключения `root` без пароля;
- runtime-проверки совместимости старой схемы;
- повреждённые README-строки и исторические дубли.
