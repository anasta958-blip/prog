# Проверка каталога

## Автоматические проверки

- `dotnet build SkladKomforta.sln --no-restore` — успешно, без предупреждений;
- `dotnet test SkladKomforta.sln --no-restore` — 48 unit и 11 API integration;
- API после Docker rebuild возвращает `Healthy` на `/health/ready`.
- `flutter test` — 24 теста, все успешно;
- `flutter analyze` — замечаний нет.
- `flutter build windows --debug` — успешно;
- `flutter build web --release` — успешно, включая WebAssembly dry run.

Unit-тесты фиксируют нормализацию пробелов и регистра, а также запрет нулевой и
отрицательной цены. Integration-тест подтверждает, что каталог недоступен без JWT.

## База

Миграция `tenant/0010_catalog_items.sql` применена к локальной тестовой схеме и
зарегистрирована в `public.tenant_migrations`. Тестовые карточки не создавались.

Flutter-тесты отдельно фиксируют загрузку конфигурации и страницы, debounce
поиска, создание товара, карточную сетку и открытие постоянного редактора без
переполнения разметки.

Также проверено позиционирование общего списка: под обычным полем и над полем,
если у нижней границы экрана для меню недостаточно места. Integration-тест
подтверждает, что профиль компании не читается без JWT.

## Ограничение этапа

Связи товаров с зависимыми категориями, явное назначение справочника полю,
импорт/экспорт и массовые операции намеренно оставлены следующими подэтапами.
Базовый CRUD каталога и выбранный Flutter-интерфейс завершены.
