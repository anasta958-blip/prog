# Конструктор ссылки и PDF

Раздел: **Компания → Конструктор ссылки и PDF**.

- **КП / ПКП**: общий набор колонок для клиентской ссылки, PDF и предпросмотра.
- **Комплектация**: колонки PDF и предпросмотра; клиентская ссылка не создаётся.

Выберите канбан. В нужной категории включите «Свой набор полей», отметьте поля,
задайте порядок кнопками со стрелками и сохраните настройки. Доступны только
поля категории, разрешённые в выбранном канбане. Порядок полей рабочего редактора
при этом не меняется. Если снять все отметки, таблица позиций категории скрывается.

Пока «Свой набор полей» выключен, сохраняется прежний стандартный вид документа.
Выключение переключателя и сохранение возвращают стандартный вид.

Изменение настроек требует права `company.manage`, просмотр — `company.view`.
Настройки общие для организации, но хранятся отдельно для каждой пары канбан/категория.
Выбранные закупочные и другие внутренние поля КП/ПКП становятся видимыми внешнему
клиенту. Неотмеченные значения не передаются в клиентскую ссылку как скрытые данные.
Шапка, названия категорий/разделов и общие итоги пока не настраиваются.

После изменения настроек заново откройте канбан/предпросмотр и обновите клиентскую
страницу. Ссылку пересоздавать не нужно. Уже скачанные PDF не изменяются.

## Обновление

До запуска обновлённого backend примените tenant-миграцию
`0046_document_layouts` ко всем организациям. Она создаёт таблицу настроек и
не изменяет данные КП, ПКП или комплектаций. Затем обновите backend и web;
Windows/Android также требуют новых сборок для интерфейса конструктора.

Текущий этап управляет составом и порядком колонок. Визуальное редактирование
текста, оформления и расположения блоков в этот этап не входит.
