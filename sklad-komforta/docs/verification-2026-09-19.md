# Проверка проекта: 19 сентября 2026

Проверка выполнялась в несколько заходов. Полные тесты и сборки завершены
до возобновления 19 сентября; 19 сентября повторно проверены запущенные
сервисы и клиентская форма в браузере. Старое PHP-приложение не изменялось.

## Исправления

- Клиентский пароль по ссылке больше не помечается как пароль учётной записи:
  используется `oneTimeCode`, контекст автозаполнения закрывается без сохранения.
- Ошибки сохранения клиентского выбора выводятся на странице. Выбор не теряется
  при ошибке; после истечения сессии можно повторно войти и продолжить.
- Устранено переполнение клиентской страницы при ширине 360 пикселей.
- Некорректный JSON и пустое тело запроса возвращают HTTP 400 вместо HTTP 500.
  Пустые логин и пароль проверяются до обработки строк.
- В рабочем журнале миграций восстановлена запись `0034_quote_client_selection`.
  Перед этим сверены существующие таблицы, связи, индекс и колонка миграции.
  Таблицы не пересоздавались, данные предложений не изменялись.

ранее загружала прежнюю сборку; после обновления приложения следует обновить
страницу без кэша (Ctrl+F5), при необходимости закрыть старые вкладки приложения.

## Повторный запуск

Из корня `sklad-komforta`, при работающем локальном PostgreSQL и заполненном `.env`:

```powershell
dotnet test SkladKomforta.sln -c Release --no-restore
docker run --detach --rm --name sklad-regression-redis --publish 127.0.0.1:16379:6379 redis:8-alpine redis-server --save "" --appendonly no
./scripts/test-database-regression.ps1
docker stop sklad-regression-redis
```

Последняя команда останавливает только тестовый Redis. Не подменять его
рабочим Redis. Скрипт сам не запускает контейнер и не выводит пароли из `.env`.

Из `src/flutter`:

```powershell
flutter analyze
flutter test
```

## Ограничения

- Физический Android-телефон, iOS и macOS не проверялись.
- Всплывающее окно менеджера паролей непосредственно в Vivaldi не проверялось;
  проверены код управления автозаполнением и DOM свежей Web-сборки.
- Не выполнен ручной обход каждого экрана и всех комбинаций пользовательских
  полей, прав и правил. Успешные тесты не доказывают отсутствие любых ошибок.
- Проверялось локальное окружение, не внешняя публикация по HTTPS и не доступ
  клиента из другой сети. Ссылка с `localhost` работает только на компьютере,
  где запущен Web-сервис.
