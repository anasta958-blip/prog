# Миграции

- `public/` содержит общие таблицы авторизации, организаций, членства и сессий.
- `tenant/` содержит шаблоны для отдельной схемы каждой организации.
- `__TENANT_SCHEMA__` заменяется только серверным provisioner-ом на имя, созданное через `TenantSchemaName.Create`. Значение из HTTP-запроса в SQL не подставляется.
- Новые изменения добавляются отдельным последовательным файлом. Уже применённые миграции не редактируются.

`tenant/0003_organization_configuration.sql` создаёт только конфигурационный
каркас будущих модулей: профиль, структуру канбанов и каталога, определения
полей, роли и справочники. Таблицы самих товаров, КП, комплектаций и документов
будут добавляться вместе с соответствующими модулями после проверки миграции
старых данных.

`tenant/0004_catalog_category_fields.sql` добавляет упорядоченную связь категории
с полями системного реестра. В таблице хранятся только код, видимость,
обязательность и порядок; название, тип и расчётная семантика поля задаются
приложением и повторно проверяются backend-ом.

`tenant/0005_catalog_category_dependencies.sql` расширяет onboarding до восьми
шагов и хранит разрешённые связи между категориями. Каждая запись указывает,
позиции какой категории можно привязать к позиции другой категории и в какое
relation-поле целевой карточки записывается связь.

`tenant/0006_workflow_categories.sql` связывает каждый канбан с выбранными
категориями каталога и хранит отдельный упорядоченный набор полей карточки для
каждой пары. Обычные поля выбираются только из настройки категории, а
расчётные поля добавляются из системного реестра.

`tenant/0007_remove_retail_price_field.sql` удаляет устаревшее поле `retail_price`
из настроек категорий, канбанов и контекстов. Рабочие цены товаров миграция не
изменяет; актуальным полем настройки цены остаётся `base_price`.

`tenant/0008_normalize_default_price_fields.sql` однократно очищает старые
onboarding-черновики от ранее автоматически добавлявшихся розничной цены,
скидки и наценки. После миграции скидку и наценку можно добавить вручную.

`tenant/0009_remove_default_line_total.sql` однократно убирает расчётное поле
`line_total` из ранее созданных стандартных наборов. Поле «Сумма» остаётся в
реестре и доступно для ручного добавления.
