# Миграции

- `public/` содержит общие таблицы авторизации, организаций, членства и сессий.
- `tenant/` содержит шаблоны для отдельной схемы каждой организации.
- `__TENANT_SCHEMA__` заменяется только серверным provisioner-ом на имя, созданное через `TenantSchemaName.Create`. Значение из HTTP-запроса в SQL не подставляется.
- Новые изменения добавляются отдельным последовательным файлом. Уже применённые миграции не редактируются.

`tenant/0003_organization_configuration.sql` создаёт только конфигурационный
каркас будущих модулей: профиль, структуру канбанов и каталога, определения
полей, роли и справочники. Таблицы самих товаров, КП, комплектаций и документов
будут добавляться вместе с соответствующими модулями после проверки миграции
старых данных.

`tenant/0004_catalog_category_fields.sql` добавляет упорядоченную связь категории
с полями системного реестра. В таблице хранятся только код, видимость,
обязательность и порядок; название, тип и расчётная семантика поля задаются
приложением и повторно проверяются backend-ом.
