# СтройСклад

Веб-приложение для каталога товаров, комплектации объектов и коммерческих предложений.

## Структура

```text
stroysklad/
|-- index.php
|-- quote.php
|-- schema.sql
|-- includes/
|   `-- auth.php
`-- api/
    |-- auth.php
    |-- catalog.php
    |-- documents.php
    |-- email.php
    |-- kp.php
    |-- orders.php
    |-- pkp.php
    `-- users.php
```

## Требования

- PHP 8.0+
- MySQL 5.7+ или MariaDB 10.3+
- Apache или Nginx с поддержкой PHP

## Установка

1. Создайте базу данных и примените `schema.sql`.
2. Настройте подключение к БД через переменные окружения `DB_HOST`, `DB_NAME`, `DB_USER`, `DB_PASS`.
3. Если переменные не заданы, локально используется fallback `localhost / kompl / root / ''`.
4. Разместите проект в директории веб-сервера.

Пример импорта схемы:

```bash
mysql -u root -p < schema.sql
```

## Основные разделы

- `Комплектация`: заявки, комплектация объекта, сотрудники, пользователи.
- `Каталог`: общий каталог товаров и монтажей.
- `КП`: каталог КП, данные компании, клиенты, составление КП и список созданных КП.
- `ПКП`: предварительные коммерческие предложения и пресеты.
- `Документы`: шаблоны документов и их версии.

## Авторизация

После входа приложение работает через сессию PHP. API ожидает активную авторизацию и возвращает JSON.

## Примечания

- Для отправки email используется `api/email.php`.
- Для отправки в Telegram используется `api/telegram.php`.
- Публичная ссылка коммерческого предложения обслуживается через `quote.php`.
