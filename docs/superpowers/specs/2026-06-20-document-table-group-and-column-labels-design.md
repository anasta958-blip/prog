# Таблицы документов: группа и пользовательские заголовки

## Цель

Добавить в таблицу позиций документов выбираемую колонку «Группа» и позволить пользователю переименовывать заголовки колонок отдельно для каждого блока таблицы.

## Модель данных

В каждом табличном блоке используются независимые свойства:

- `column_keys` — выбранные колонки и их порядок.
- `column_widths` — пользовательская ширина колонок.
- `column_labels` — пользовательские заголовки по ключу колонки.

Пример:

```json
{
  "column_keys": ["group_name", "name", "quantity"],
  "column_widths": {
    "group_name": "120px"
  },
  "column_labels": {
    "group_name": "Товарная группа",
    "name": "Позиция"
  }
}
```

Пустое или отсутствующее значение в `column_labels` означает использование стандартного заголовка.

## Колонка «Группа»

- Новый ключ: `group_name`.
- Стандартный заголовок: «Группа».
- Источник значения: `item.group_name`.
- Если группа отсутствует, выводится `—`.
- Колонка доступна только обычной таблице позиций.
- Колонка не добавляется автоматически в старые и новые таблицы, пользователь включает её в панели колонок.

## Панель колонок

Для каждой включённой колонки отображаются:

- переключатель видимости;
- ручка изменения порядка;
- поле пользовательского заголовка;
- поле ширины.

Изменение заголовка:

- применяется только к выбранному блоку таблицы;
- сразу обновляет preview;
- сохраняется в локальном черновике и payload шаблона;
- не влияет на определение данных колонки;
- при очистке поля возвращает стандартное название.

## Совместимость

- Старые документы без `column_labels` продолжают работать со стандартными заголовками.
- `column_keys`, `column_widths`, перестановка и изменение ширины сохраняют текущую логику.
- Пользовательские заголовки применяются в preview, печати и HTML-экспорте через единый renderer таблиц.
- API и схема базы данных не меняются, поскольку свойства сохраняются внутри payload документа.

## Проверка

Автоматические тесты должны подтвердить:

- колонка `group_name` доступна таблице позиций;
- значение группы берётся из позиции;
- пользовательский заголовок применяется только к своему блоку;
- пустой пользовательский заголовок возвращает стандартный;
- пользовательский заголовок присутствует в preview и экспортной разметке;
- старый блок без `column_labels` отображается без ошибок.
